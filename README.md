# ANWAR | Design & Code

المستودع الرسمي لواجهة موقع **ANWAR**، وهو مركز رقمي عربي لخدمات التصميم الجرافيكي والبرمجة والكتب والقوالب الرقمية.

## النشر

يُنشر الموقع تلقائيًا عبر GitHub Pages عند الدفع إلى فرع `main`. رابط الموقع الرسمي بعد أول نشر هو:

`https://ANWAREASDZX.github.io/anwar-digital-hub/`

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

## البناء

```bash
pnpm exec vite build
```

الأصول البصرية داخل `client/public/assets` مخصصة للنشر العام مع الموقع. لا تحفظ في هذا المستودع أي مفاتيح أو أسرار أو بيانات عملاء.
